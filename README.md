# Photo Coloring public catalog

This repository contains only the public static catalog and runtime artwork used by the Photo Coloring app. The source app and artwork-authoring workspace remain in the private `lucky-game-studio` repository.

`current.json` points to an immutable catalog revision. Catalog entries carry explicit display order and thumbnail paths. Selecting a page loads its metadata, line art, and source image from that revision. The payload was generated by `games/photo-coloring/scripts/build_pages_catalog.py`.

GitHub Pages is deployed from this repository's root by the `Publish Photo Coloring content` workflow. Public URL: https://vnluckystudio.github.io/photo-coloring-content/.
